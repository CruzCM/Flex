Slide 1 — Agentes modernos e o template

Agentes modernos e o template

Usuário → LLM / Agente → Resposta

- Usuário no lado esquerdo.
- LLM / Agente no centro.

Slide 3 — RAG
Crie um diagrama editável para o slide:

RAG

Preserve a estrutura visual estabelecida anteriormente:

Usuário à esquerda.
Resposta à direita.
LangGraph no centro.

Dentro da área:

LangGraph — fluxo do agente

coloque:

LLM / Agente
RAG Tool

Posicione LLM / Agente como elemento central.

Posicione RAG Tool abaixo ou próximo ao LLM / Agente, formando um pequeno ciclo.

Conexões dentro do LangGraph:

LLM / Agente → RAG Tool
Rótulo: Buscar contexto

RAG Tool → LLM / Agente
Rótulo: Contexto

Fora da área LangGraph, posicione:

Genera BB

Coloque Genera BB próximo da RAG Tool, mas claramente fora da área LangGraph.

Conexões:

RAG Tool → Genera BB

Genera BB → RAG Tool
Rótulo: Chunks

Fluxo principal:

Usuário → LLM / Agente

LLM / Agente → Resposta

A leitura do diagrama deve permitir entender esta sequência:

1. O usuário envia uma solicitação.
2. O agente identifica que precisa de contexto.
3. O agente chama a RAG Tool.
4. A RAG Tool consulta o Genera BB.
5. O Genera BB retorna chunks.
6. A RAG Tool devolve contexto ao agente.
7. O agente continua o fluxo e gera a resposta.

Todos os elementos devem permanecer editáveis.

Tools e MCP

APIs / Sistemas
